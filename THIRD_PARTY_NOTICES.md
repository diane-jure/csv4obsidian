# Third-party notices

CSV4Obsidian was designed after studying two MIT-licensed Obsidian plugins.
No source code was copied; the look and feature set were inspired by them.

- **CSV Lite** by Jay Bridge (LIUBINfighter) — https://github.com/LIUBINfighter/csv-lite — MIT License.
  Inspiration: lettered column headers, numbered rows, whole row/column selection, highlight styling.
- **Omni Viewer** by battlecook — https://github.com/battlecook/omni-viewer-obsidian — MIT License
  (CSV viewer from `omni-viewer-core`).
  Inspiration: font size and cell proportions, content-sized columns, zebra rows, column sorting,
  statistics, search.
